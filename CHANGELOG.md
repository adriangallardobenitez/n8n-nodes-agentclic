# Changelog

## 0.1.0

- First version of the Agentclic node and the Agentclic API credential.
- Account: Get (token details and credit balance).
- Client: Get Many.
- Contact: Create, Create or Update, Get, Get Many (search, filters, cursor pagination) and Update.
- Dynamic lists for clients, contacts, stages, custom fields and origins.
- Clear error messages for Agentclic API errors, and one automatic retry on rate limit (429).
- Usable as a tool by the n8n AI Agent.
